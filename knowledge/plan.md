# 《巷口有事》遊戲願景與開發路線圖

更新日期：2026-11-19

## 遊戲願景

打造一款以台南中西區為舞台的第三人稱開放街區動作冒險遊戲。玩家扮演阿翊，在熟悉的街巷中自由探索、接任務、騎乘機車、賺取酬勞，再用收入購買或升級交通工具與遊戲裝備。遊戲有追逐、突發事件、誇張橋段與台味幽默，也保留阿翊守護街坊、熟人與日常生活的情感核心。

目標是先做出可操作、有明確任務循環的小型試玩區，再逐步擴大。街道和主要路口盡量參考真實中西區；建築、人物和美術風格可以風格化，但希望呈現更可信的街屋尺度、道路關係、生活細節與光影。最終願景是讓玩家認得出家齊高中及五妃街周邊，並能在此自由移動與完成任務。

本作借鑑開放世界犯罪動作遊戲的自由探索、載具移動、追逐與任務節奏；角色、故事、地名改編、任務和美術採原創設計。

## 故事與核心設定

- **主角：阿翊。** 一直住在中西區，熟悉街坊與巷弄；故事起點與家齊高中有關。
- **故事開端：** 阿翊在家齊高中附近意外拿到一支陌生手機，手機訊息把他捲進地方勢力、失竊帳本與一場廟會夜追逐。故事調性勁爆、帶黑色幽默和台味對白。
- **遊戲循環：** 接取街坊委託或主線任務 → 探索、追逐或送達目標 → 領取酬勞 → 添購或升級車輛及遊戲裝備 → 解鎖更具挑戰的任務。
- **任務完成後：** 應立即提供下一個委託、可追蹤的任務列表或自由活動目標，避免玩家完成單一任務後無事可做。
- **內容方向：** 任務和裝備服務於虛構的街機式冒險與遊戲平衡。學校和真實街區的室內、人物與事件採創作化處理。

## 場景方向

第一個重點區域是家齊高中與五妃街周邊。場景先重建道路走向、路口、校園區塊、騎樓和周邊店屋，再逐步補入招牌、路樹、電線、機車、行人、店面細節及任務互動。街區空間關係以實地資料校對；建築模型可簡化，不以每間室內都可進入為首期目標。

家齊高中官方資料列出校址為臺南市中西區健康路一段342號；官方校園配置圖標示五妃街、忠義路、永福路與健康路等周邊道路。本專案應以官方校園位置圖與後續地圖／實地參考校正道路方向及校園區塊，不能把目前簡化的程式生成街廓當成精確測繪結果。

## 路線圖

### 目前狀態

- 專案已有單頁 Three.js 瀏覽器原型，具備第三人稱跟隨鏡頭、鍵盤移動、滑鼠拖曳轉鏡頭、快跑和機車騎乘雛形。
- `index.html` 已加入家齊高中校園區塊與五妃街／健康路／永福路／忠義路的簡化空間關係，並開始補上街屋、路樹、校舍和校園入口。
- 阿翊模型已加入髮型、臉部細節、衣著、背包和基本四肢擺動；仍屬幾何原型，尚未達到精細角色模型。
- 3D 原型已加入四種可輪替街坊委託、E 鍵交付、酬勞累積與下一個任務標記。任務完成後會循環提供下一項。
- 最新場景與互動改動尚未在瀏覽器完成視覺與操作確認；現有街道仍是人工簡化布局，不能視為精確測繪。
- `knowledge/plan.md` 已建立，作為後續功能與進度的單一規劃文件。

### 剩餘項目

#### 近期：完成可玩的街區任務循環

- [ ] 在瀏覽器確認 3D 場景能載入，並確認角色移動、機車上下車、任務交付、現金與任務輪替都正常。
- [ ] 改善機車騎乘時阿翊的姿勢與車手／車輛位置同步，加入可辨識的上下車動作及提示。
- [ ] 調整角色身形比例、面部可讀性、衣物層次與跑步動畫；目前模型仍由簡單幾何構成。
- [ ] 加入可用任務報酬購買或升級機車的車行介面；目前只有酬勞數字，沒有商店流程。
- [ ] 確認任務標記、交付位置和道路可達性相符，處理目前簡化街區可能存在的穿模或阻擋問題。

#### 中期：提高家齊高中與五妃街區域的可信度

- [ ] 依官方校園配置圖和可靠地圖資料校正校園大小、四周道路、主要路口與道路寬度；目前只有粗略相對位置。
- [ ] 將五妃街、健康路、永福路、忠義路，以及附近巷弄細化為可辨識的街廓，校正人工放置的道路、店屋和校地重疊。
- [ ] 補上台南街屋／騎樓尺度、店面招牌、騎樓柱、機車停放、路樹、電線桿、標線、斑駁路面等環境細節。
- [ ] 增加可互動 NPC、店家與任務地標，加入街坊日常與任務事件。
- [ ] 校園場景採虛構化細節，避免把真實學生或未經確認的校內空間當成劇情事實。

#### 後期：擴充開放世界內容

- [ ] 增加更多中西區街區和地標，逐區擴大可探索地圖。
- [ ] 加入多類任務：跑腿、競速、追逐、尋物、護送、調查與主線劇情。
- [ ] 建立車輛／裝備購買與升級介面、價格、性能差異及任務解鎖條件。
- [ ] 加入存檔、任務紀錄、地圖導引、音效、對白與音樂。
- [ ] 依實際效能調整模型細節、陰影、碰撞、行人和交通行為。

## 待定設計

- 遊戲引擎與最終發行平台：目前使用瀏覽器版 Three.js 做原型，尚未決定是否移植到 Unity 或其他引擎。
- 主角完整背景、年齡、朋友與對立勢力，以及主線結局。
- 首發地圖範圍、任務總量、經濟數值與裝備種類。
- 地圖資料、實地照片和真實商家名稱的使用方式；必要時採虛構店名與招牌。
